# 2026-07-28

## Open Music Evidence Floor — make every organ interoperable without laundering authority

**State:** The repository already had provider seams for stems, notes, retrieval,
embeddings, vector search, and artifacts; cross-organ evidence branches; exact MIDI,
racks, MixScore, live execution, and specimen gates. The commodity and community
sweep showed that the ecosystem already supplies most individual organs, but no
portable contract consistently binds evidence tier, provider authority, source
custody, source/performance time, phrase substitutability, rights assertions,
independent evaluation, review causality, and portable receipts.

**Did:**

- Added the language-agnostic `earcrate-floor-stdio-json` v1 protocol.
- Added canonical ProviderManifest, ProviderRequest, ProviderResult, TimeMap,
  PhraseContract, RightsEnvelope, ReviewPatch, InvocationReceipt,
  EvaluationPolicy, EvaluationLedger, TournamentReport, ConformanceReport, and
  FloorCrate authorities.
- Made request and semantic-result identities independent of machine-local paths.
- Added exact input/output custody, artifact containment, symlink and traversal
  refusal, argv-only execution, resource limits, and honest network-declaration
  receipts.
- Added catalog discovery with malformed/conflicting manifest refusals and
  compatibility filtering that does not pretend to rank or select.
- Added an independent-evaluator contract and hard-gate/lexicographic provider
  tournaments whose winners remain non-authoritative.
- Added JAMS, W3C PROV, ODRL, and RO-Crate mappings with checksums and no default
  source-media copying.
- Added a movable standard-library reference provider that imports no EarCrate
  code, plus package and single-file conformance commands.
- Projected the existing EarCrate provider registry into honest in-process Floor
  manifests without claiming subprocess conformance.
- Added an executable gap register covering implemented, partial, open,
  boundary, and owner-decision surfaces.
- Added fourteen committed JSON Schemas, provider protocol and cookbook docs,
  README entrypoints, and eleven executable gates.

**Verified locally:**

- 11/11 focused Floor gates passed under pytest and the repository gate runner.
- Reference-provider two-run conformance is semantically repeatable.
- Package and generated single-file artifacts execute the same protocol.
- `VERIFY_PACKAGE.py --skip-gates` passed every package, self-test, UI, MIDI,
  rack, live, and live-audio smoke.
- OSS audit passed with no new runtime dependency.

**Honest boundary:** The v1 reference host records network policy but does not
prove an OS network sandbox; it applies process timeout and output limits but not
full CPU/memory/GPU isolation. The normative protocol is still under the project
license; a universal commercial standard requires an owner-approved permissive
license for schemas, vocabulary, examples, and conformance fixtures.
